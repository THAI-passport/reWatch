# C900 open companion: Android (Kotlin)

Phase 3a, approved 2026-10-13 (targets/c900/OPEN-QUESTIONS.md). Design: targets/c900/CLIENT-DESIGN.md.

## Modules
| Module | State | What |
|---|---|---|
| `core` | built and tested (pure Kotlin/JVM, no Android imports) | `Frames` codec (port of `client/c900/frames.py`), `FrameReader` (resync, flood caps), `Gatt` (command UUIDs, OTA/unknown-service deny list, QR->MAC per S-22), `Commands` (the only frame builders: time, find, message, 12/24 h, feature query), `CommandQueue` (one in flight, ack match, 100 s timeout, write budget, no auto-resend), `Session` (connect order, ver from 0x2A27, feature gating, bond triggers become a user prompt) |
| `app` | not started | Compose UI (Lucide icons, no emoji, no ads), BLE transport on `BluetoothGatt` bound to command-service characteristic objects, CompanionDeviceManager, NotificationListenerService, Room storage |

## Build and test
```bash
cd client/c900-android
gradle :core:test          # Gradle 8.x, JDK 21; the Kotlin plugin comes from Maven Central / plugin portal
```
Tests read `tests/fixtures/c900_vectors.json`, generated by the Python reference:
`python -m client.c900.vectors > tests/fixtures/c900_vectors.json` (a Python test fails if it is stale).

The `app` module needs the Android Gradle plugin from Google Maven (dl.google.com), which the cloud session cannot reach; build it on the owner's machine (FIXES.md Open).

## Safety carried over from the probe
Blocked commands cannot be built; only allowlisted (cmd, key) pairs have builders; bind (cmd 3) is absent until a separate decision; the transport must refuse denied UUIDs (`Gatt.isDenied`); unknown ver values or a missing command service stop the session; the client never calls `createBond` without the user saying yes. The simulator in the tests proves consistency only.
