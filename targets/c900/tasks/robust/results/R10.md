## Summary
Analyzed the Android background execution and permission architecture of Hiwear Plus 2.0.1.
The vendor app relies on an aggressive dual-process watchdog (`MessageService` and `ProtectService` in `:RemoteProcess` mutually binding via AIDL), `NotificationListenerService` (`NPNotificationService`), `JobScheduler` (`AliveJobService`), and an ongoing foreground notification (`MsgPushService` with `connectedDevice` type).
The vendor manifest contains 33 permissions including surveillance and advertising SDK capabilities (SMS, Contacts, Call Log, Camera, Microphone, Internet).
Constructed a lean, privacy-preserving manifest specification for the open client: 6 permissions kept, dual-process hack replaced with standard Android ForegroundService + WorkManager, zero network permissions, zero contact/SMS permissions.

## Component & Permission Classification (Keep / Replace / Drop)

| Item in Vendor Manifest | Category | Verdict | Rationale / Open Client Treatment |
|---|---|---|---|
| `BLUETOOTH_SCAN` | Permission | **KEEP** | Essential for discovering C900 BLE advertisements. Add `android:usesPermissionFlags="neverForLocation"` to avoid location permission prompts. |
| `BLUETOOTH_CONNECT` | Permission | **KEEP** | Required on Android 12+ (API 31+) to connect to the watch GATT server. |
| `FOREGROUND_SERVICE` | Permission | **KEEP** | Required on Android 9+ to run persistent connection service. |
| `FOREGROUND_SERVICE_CONNECTED_DEVICE` | Permission | **KEEP** | Required on Android 14+ (API 34+) for BLE companion device services. |
| `POST_NOTIFICATIONS` | Permission | **KEEP** | Required on Android 13+ (API 33+) to show the ongoing connection notification. |
| `RECEIVE_BOOT_COMPLETED` | Permission | **KEEP** | Allows app shell to automatically reconnect to the watch after phone reboot. |
| `WAKE_LOCK` | Permission | **KEEP** | Transient wake lock during ATT packet chunk queue flush. |
| `NPNotificationService` | Service | **KEEP** | Standard Android `NotificationListenerService` to capture app notifications for forwarding. |
| `MessageService` + `ProtectService` | Service | **REPLACE** | Vendor uses aggressive dual-process AIDL watchdog (`:RemoteProcess`). Replace with a single well-behaved Android foreground service and modern WorkManager periodic checks. |
| `AliveJobService` | Service | **REPLACE** | Replace ad-hoc JobService with standard AndroidX `WorkManager`. |
| `ACCESS_FINE_LOCATION` | Permission | **DROP** | Completely unnecessary on Android 12+ when `neverForLocation` is specified. Legacy Android 6-11 only needs coarse location if supported. |
| `ACCESS_COARSE_LOCATION` | Permission | **DROP** | Drop for Android 12+ targets. |
| `INTERNET` | Permission | **DROP** | **CRITICAL:** Open client is 100% local-only. Zero network connectivity prevents all remote telemetry, ad tracking, and data exfiltration. |
| `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` | Permission | **DROP** | No network logic exists in local client core. |
| `READ_SMS`, `RECEIVE_SMS` | Permission | **DROP** | Unnecessary: notifications from messaging apps are received via `NotificationListenerService`. |
| `READ_CONTACTS`, `WRITE_CONTACTS` | Permission | **DROP** | Vendor used for contact sync and caller name lookups. Open client leaves phonebook private. |
| `READ_CALL_LOG` | Permission | **DROP** | Invasive; caller alerts can be forwarded directly from incoming call notifications. |
| `CAMERA`, `FLASHLIGHT` | Permission | **DROP** | Vendor used for remote watch shutter and QR scanning. Can use system photo picker or drop entirely. |
| `RECORD_AUDIO` | Permission | **DROP** | Vendor voice assistant / audio recording. Not in client scope. |
| `READ/WRITE_EXTERNAL_STORAGE` | Permission | **DROP** | Open client uses internal scoped app storage (`context.filesDir`). |
| Facebook SDK, Tencent Map, Google Geo | Third-party | **DROP** | Third-party tracking, ad libraries, and social login SDKs completely purged. |

## Proposed Manifest for Open Client Shell (`client/c900-android`)

```xml
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools">

    <!-- BLE connection & scanning (API 31+) without location access -->
    <uses-permission
        android:name="android.permission.BLUETOOTH_SCAN"
        android:usesPermissionFlags="neverForLocation"
        tools:targetApi="s" />
    <uses-permission
        android:name="android.permission.BLUETOOTH_CONNECT"
        tools:targetApi="s" />

    <!-- Legacy BLE for Android 10-11 (optional) -->
    <uses-permission
        android:name="android.permission.BLUETOOTH"
        android:maxSdkVersion="30" />
    <uses-permission
        android:name="android.permission.BLUETOOTH_ADMIN"
        android:maxSdkVersion="30" />

    <!-- Foreground connection & notification rules -->
    <uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
    <uses-permission
        android:name="android.permission.FOREGROUND_SERVICE_CONNECTED_DEVICE"
        tools:targetApi="upside_down_cake" />
    <uses-permission
        android:name="android.permission.POST_NOTIFICATIONS"
        tools:targetApi="tiramisu" />

    <!-- Device reboot auto-reconnect & packet wake lock -->
    <uses-permission android:name="android.permission.RECEIVE_BOOT_COMPLETED" />
    <uses-permission android:name="android.permission.WAKE_LOCK" />

    <application
        android:allowBackup="false"
        android:icon="@mipmap/ic_launcher"
        android:label="reWatch"
        android:theme="@style/Theme.ReWatch">

        <!-- Main BLE Connection Service -->
        <service
            android:name="rewatch.c900.service.C900BleService"
            android:enabled="true"
            android:exported="false"
            android:foregroundServiceType="connectedDevice" />

        <!-- Notification Listener Service (user-enabled in Android settings) -->
        <service
            android:name="rewatch.c900.service.NotificationForwarderService"
            android:permission="android.permission.BIND_NOTIFICATION_LISTENER_SERVICE"
            android:exported="true">
            <intent-filter>
                <action android:name="android.service.notification.NotificationListenerService" />
            </intent-filter>
        </service>

        <!-- Boot Receiver for reconnect -->
        <receiver
            android:name="rewatch.c900.receiver.BootReceiver"
            android:enabled="true"
            android:exported="false">
            <intent-filter>
                <action android:name="android.intent.action.BOOT_COMPLETED" />
            </intent-filter>
        </receiver>

    </application>
</manifest>
```
