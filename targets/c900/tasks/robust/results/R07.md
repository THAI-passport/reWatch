### Kotlin core (what, why, test that would catch it)
In `client/c900-android/core/src/main/kotlin/rewatch/c900/Frames.kt`:
Override `equals()` and `hashCode()` on `data class Cmd`:
```kotlin
data class Cmd(val cmd: Int, val ver: Int, val key: Int, val payload: ByteArray) : Inbound() {
    override fun equals(other: Any?): Boolean {
        if (this === other) return true
        if (other !is Cmd) return false
        return cmd == other.cmd && ver == other.ver && key == other.key && payload.contentEquals(other.payload)
    }
    override fun hashCode(): Int {
        var result = cmd
        result = 31 * result + ver
        result = 31 * result + key
        result = 31 * result + payload.contentHashCode()
        return result
    }
}
```
Why: Standard Kotlin data classes generate `equals()` on `ByteArray` fields using identity comparison (`===`), causing two `Cmd` instances with identical byte payloads to fail structural equality comparisons.
Test that would catch it: `assertEquals(Cmd(2, 16, 11, byteArrayOf(1)), Cmd(2, 16, 11, byteArrayOf(1)))`.
