## Summary
Notifications are captured by NPNotificationService and forwarded via MsgPushHelper as cmd 0x02 key 18 frames.
Package names map to 24 known application categories; all unmapped apps map to Other (type 255/0xFF).
Text is formatted as "title:body" in UTF-8, hard-truncated to 196 bytes preceded by 3 header bytes (type, 0, 0).
Because feature byte 15 bit 0x02 is set on the C900 Watch Ultra, the new notification type table (with Messenger=19, Telegram=21, etc.) applies.
Incoming call alerts (cmd 0x02 key 17) push only during ringing (state=1) as "1, 0, UTF-8(contact_or_number)".

## Text rules for the core
1. Format: `val text = if (title.isEmpty()) body else "$title:$body"`
2. Truncation: Slicing must not split a multi-byte UTF-8 character. Encode to UTF-8, if length > 196 bytes, find the last valid UTF-8 code point boundary <= 196 bytes to avoid garbled characters on the watch screen.
3. Outbound Payload:
   - Byte 0: `type.toByte()`
   - Byte 1: `0x00`
   - Byte 2: `0x00`
   - Bytes 3..: UTF-8 bytes (max 196 bytes)
4. Call Alert Payload (cmd 0x02 key 17):
   - Byte 0: `0x01` (Ringing)
   - Byte 1: `0x00`
   - Bytes 2..: UTF-8 contact name or phone number
