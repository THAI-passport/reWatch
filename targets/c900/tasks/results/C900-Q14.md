## Step 2 — cmd 0x09 settings reply (`UserInfoAndRemindUtils.parsingUseInfoAndRemind`) [C; smali start `0xe`, packed-switch from 2]
Records start at **frame index 14** (frame bytes 9-13 are skipped; meaning [U]). Each record = tag byte + fixed fields; integers u16 BE; windows are minute-of-day.
| tag | Length after tag | Fields |
|---|---|---|
| 2 | 4 | step goal u32 BE (logged only) |
| 3 | 8 | sedentary: lunchBreak, switch, threshold u16, (min-30)/15, start h, end h, repeat (7 bits) |
| 4 | 11 (+1) | old notify switches: tel, sms, wechat, qq, facebook, twitter, skype, line, whatsapp, kakao, instagram; a 12th byte of 0 or 1 is consumed as an extra switch |
| 5 | 5 | sleep window: switch, start u16, end u16 |
| 6 | 4 | b1 bit 0x02 clear = left hand; b2 bit 0x02 = Android flag; b3 language code; b4 bit 0x01 vibration |
| 7 | 5 | raise-to-wake window (switch, start, end); switch 1 clears all-day light-up if supported |
| 8 | 8 | heart auto: switch, sleep, cycle u16, start u16, end u16 |
| 9 | 5 | DND window; switch 1 clears all-day DND if supported |
| 10 | 7 | temperature auto: switch, cycle u16, start u16, end u16 |
| 11 | 1 | bit 0x01 clear = 24 h (consistent with outbound key 26: 0 = 24 h) |
| 12 | 0 | (no fields) |
| 13 / 15 | 1 | Viber / Zalo switch |
| 14 | 1 | temperature unit |
| 17 / 18 | 1 | all-day light-up / all-day DND switch |
| 16, other | 0 | skipped |
The jadx loop for tags 4, 7, 9, 11 has awkward index arithmetic; the lengths above follow jadx [C jadx]; a capture should confirm.

## Step 3 — cmd 0x0F face replies (`BleDataUtils.handleWatchFaceInfo` + dispatcher) [C jadx]
Payload `p` from frame byte 9. Code width `w` = 8 if feature `is8Bytes` (b18 0x40), else 2.
| key | Fields |
|---|---|
| 2 (and 9, same layout) | `p[0]` face count n; `p[1..w]` current face code; then n codes of w bytes. Default sizes by `deviceResolutionRatio`: 1 -> dial 266240 / paper 118784; 2 -> dial 90112 / paper (library constant, value [U]); >= 16 -> paper u32 BE at `p[-8..-5]`, dial u32 BE at `p[-4..-1]` |
| 5 | custom face: code (w bytes), timeX u16, timeY u16, color u16, aboveTime, belowTime, bgUpdate (same as outbound key 5) |
| 6 / 8 | frame byte 9 = 1 -> custom face / custom dial updated (UI refresh) |
Sync: keys 2, 5, 9 advance the connect sync sequence (Q05).
