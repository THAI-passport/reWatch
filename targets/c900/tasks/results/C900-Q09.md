## 2. Auth style [C, shape only]
- Every endpoint takes a `@QueryMap` (GET) or `@FieldMap` (POST); no auth headers (only `User-Agent`, and `Accept` for SSE).
- Requests are signed with a `sign` parameter: the app adds a seconds timestamp and, for logged-in calls, the stored access token; sorts keys; joins non-empty, non-`"0"` pairs as `k=v&`; appends `key=<app secret>`; MD5 (32 hex). The app secret is a literal in the code and is **deliberately not recorded**.
- The Tencent Cloud speech module (`com.lhzl.speech`) contains credential-like identifiers; values not recorded.
