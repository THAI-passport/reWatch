# C900-Q05 — Inbound DF payload map

Date: 2026-10-13 (Asia/Saigon). Static only (jadx + smali). Status: **partial** (stopped under OPEN-QUESTIONS stop condition (b): a value conflicts with FACTS.md; recorded there, no winner picked).

## Stop reason
FACTS §2 row "No bonding" and PROTOCOL §3 say there is no `createBond` call in the app's own code [C]. Smali shows three app-code call sites of `BluetoothDevice.createBond`:
- `BleDataUtils.setDeviceContro(BB)` (inbound cmd 0x0C key 19; only when bond state is BOND_NONE = 10),
- `BleDataUtils.setSettingSuccess(BI)` (FD-ack follow-up; PROTOCOL §7 already said "may createBond"),
- `MainActivity$4.run()`.
Plus the two BLESSED library sites. Reproduce: `rg -n "BluetoothDevice;->createBond" targets/c900/work/smali | grep -v welie`. Recorded in FACTS §4 as a conflict. Whether the C900 asks for bonding stays [U] (C900-Q03).

## Mapped before the stop [C, `NotifyWriteUtils.dataHandle` unless named]
Reassembly: notifications are concatenated until `len + 4` bytes; sum over all bytes except index 3 must equal byte 3; good -> ACK `x=0 status 1`, bad -> NAK `x=3 status 0` (see C900-Q04). Fields: cmd at byte 4, key at byte 6, payload from byte 9.

### Feature map (0x2A28 read and cmd 0x19 reply) [C jadx, `NotifyWriteUtils.readFeatures`]
Byte 0 must be 0xAA. Bits used by first contact: b1: 0x80 BLE3, 0x40 contacts, 0x10 temperature, 0x08 12/24 h switch, 0x04 unit switch, 0x02 language, 0x01 SpO2. b2: 0x80 face set, 0x40 face customize, 0x20 face push, 0x10 (clear = choose paper), low nibble resolution. b3: 0x40 Viber, low nibble screen shape. b4-b11 language bitmap. b13 sport modes. b14: 0x80 hide HR, 0x40 hide BP, 0x20 call push, 0x10 SOS, 0x08 200 contacts, 0x01 Zalo. b15: 0x80 (clear = raise-to-wake), 0x40 pairing, 0x04 drink, 0x02 new message table. b16: 0x80 scan connect, 0x40 OTA, low 6 bits resolution. b17 code format. b18: 0x80 RGB565, 0x40 8-byte face code, **0x20 `binPreviewFlag`** (dial trim off, see Q06), 0x08 7-day weather, 0x04 user name, 0x02/0x01 DIY wallpaper. b19-b27: sedentary, payment, MAC xor 0x55, social, vibrate, page visibility, DND, power save, find-phone exit, altitude, location, assistant. jadx shows both `isShowHrAutoTest` and `isShowDnd` on b25 0x80; not yet smali-checked.
